# Rock Paper Scissors (Python)

This is a simple terminal-based Rock Paper Scissors game I built, while practising some of the Python fundamentals. It uses ASCII art to display each choice, takes the user input, generates a completely random computer move, and decides the winner based on the original game's rules. It's a small project, but it helped with my comfortability with lists, conditionals, and basic game logic.

---

## What It Does

- Lets you choose between Rock, Paper, or Scissors
- Shows every choice using ASCII art
- Makes the computer generate a random decision
- Finds out the winner based on simple logic
- Handles valid inputs
